# llms.txt—a proposal to provide information to help LLMs use websites

[https://www.answer.ai/posts/2024-09-03-llmstxt.html](https://www.answer.ai/posts/2024-09-03-llmstxt.html)

## Description

This webpage proposes adding a /llms.txt file to websites designed for reading by language models to help them better utilize website content.

## Summary

The article suggests that website owners create a /llms.txt file, which acts as a markdown resource providing background information and guidance tailored for language models (LLMs). This file would include links to more detailed markdown files relevant to the website's content, facilitating a more effective way for LLMs to scrape and understand pertinent information. It highlights the importance of allowing authors to define the context that LLMs can retrieve, making content ingestion clearer and more structured.

The proposed llms.txt format would include various sections such as a project title, a brief summary, detailed explanations, and links to external resources. This method simplifies how LLMs gather necessary information, addressing challenges like ambiguity in data retrieval. Additionally, the article recommends providing a clean markdown version of existing web pages to streamline content consumption by LLMs.

By adopting this standard, creators can enhance the interaction between their content and LLMs, making it easier for models to access relevant information. The proposed structure is both human-readable and conducive to automated parsing, paving the way for improved documentation approaches across various domains, including software libraries and educational resources.
