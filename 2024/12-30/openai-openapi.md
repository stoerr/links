# GitHub - openai/openapi - OpenAPI specification for the OpenAI API

[https://github.com/openai/openai-openapi](https://github.com/openai/openai-openapi)

## Description

OpenAPI specification for the OpenAI API.

## Summary

This repository contains an OpenAPI specification for the OpenAI API, which serves as a public mirror of the internal OpenAI REST API specification. Contributions to the specification document are not currently accepted, although there may be potential for collaborative improvements in the future.

The OpenAPI specification outlines the standard operations and functionalities that developers can leverage when interacting with the OpenAI API. This document plays a crucial role in facilitating the development and integration of applications utilizing OpenAI's offerings. 

The repository is licensed under the MIT license, allowing users to reference and utilize the API definition freely, subject to the terms of the license.
