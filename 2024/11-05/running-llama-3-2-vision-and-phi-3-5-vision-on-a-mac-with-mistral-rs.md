# Running Llama 3.2 Vision and Phi-3.5 Vision on a Mac with mistral.rs

[https://simonwillison.net/2024/Oct/19/mistralrs/](https://simonwillison.net/2024/Oct/19/mistralrs/)

## Description

A guide on running the Llama 3.2 Vision and Phi-3.5 Vision models on a Mac using the Rust-based library mistral.rs.

## Summary

The article discusses how to utilize the Rust library mistral.rs to run the Llama 3.2 Vision and Phi-3.5 Vision models on a Mac. It outlines the necessary steps to clone the library, compile it, and run the models, including downloading the model files and checking the system's performance metrics like memory usage and GPU utilization. 

Additionally, the author provides insights into using the models interactively with image prompts and notes some discrepancies between the generated descriptions and actual image contents, highlighting the issue of hallucinations in AI outputs. The article concludes with recommendations for Python users and offers a link to a pre-built wheel to simplify installation.
