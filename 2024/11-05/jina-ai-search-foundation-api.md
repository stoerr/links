# Jina AI - Your Search Foundation Supercharged

[https://docs.jina.ai/](https://docs.jina.ai/)

## Description

A comprehensive guide to using the Jina AI Search Foundation APIs for various use cases.

## Summary

The Jina AI Search Foundation provides a set of robust APIs designed for classification, embeddings, reading web content, searching the web, verifying factual accuracy, and segmenting text. Each API has specific capabilities, such as classifying texts or images, generating embeddings for semantic search, and extracting structured content from web pages. The document emphasizes the importance of handling API errors and the limitations of the APIs, clarifying that they cannot perform actions beyond those explicitly defined.

The guide also lists endpoint details for each API, along with example requests and responses to facilitate implementation. Users are encouraged to leverage built-in features whenever possible, use environment variables for API keys, and ensure that they correctly parse the responses from API calls to make the most of the Jina AI Search Foundation. Overall, the document serves as an essential resource for developers looking to incorporate Jina's capabilities into their applications efficiently.
