# Introducing the Model Context Protocol - Anthropic

[https://www.anthropic.com/news/model-context-protocol](https://www.anthropic.com/news/model-context-protocol)

## Description

The Model Context Protocol (MCP) is an open standard for connecting AI assistants to the systems where data lives, including content repositories, business tools, and development environments.

## Summary

Today, Anthropic announced the open-sourcing of the Model Context Protocol (MCP), which seeks to overcome the challenge of AI systems being isolated from key data sources. This new, universal standard replaces the need for fragmented integrations by allowing developers to create secure, two-way connections between AI tools and various data sources, streamlining access to relevant information.

The MCP comprises three primary components for developers, including the specification and SDKs, support for local MCP servers, and an open-source repository of MCP servers. Companies like Block and Apollo are already incorporating MCP into their systems to enhance the capabilities of AI agents, leading to better retrieval of relevant information and improved contextual understanding. Anthropic invites the developer community to collaborate in building a future for context-aware AI.
