# Generative AI Scripting - GenAIScript

[https://microsoft.github.io/genaiscript/](https://microsoft.github.io/genaiscript/)

## Description

GenAIScript, scripting for Generative AI.

## Summary

GenAIScript is a JavaScript-based toolkit designed for programmatically assembling prompts for Large Language Models (LLMs). It aims to merge scripting, tools, and data into one seamless experience, providing features like a JavaScript toolbox for prompt creation, integration with Visual Studio Code, and easy handling of files and data through defined functions. The tool encourages a rapid development cycle with debugging and testing capabilities.

The platform is illustrated with examples, such as creating a simple 'hello world' poem through user-friendly code snippets, manipulating document content like PDFs and CSVs, and generating structured outputs. Furthermore, developers can define data schemas for validation and create reusable scripts that can be versioned and shared. GenAIScript also includes automated tools for various applications, including browser automation, data analysis, and safety checks.

In additional features, GenAIScript allows integration with existing models such as those from GitHub and supports local AI models. Users can automate scripts, run tests, and employ rich contextual tools for comprehensive project management, making it a powerful asset for developers interested in leveraging generative AI in their workflows.
