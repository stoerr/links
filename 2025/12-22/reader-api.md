# Reader API

[https://jina.ai/reader/](https://jina.ai/reader/)

## Description

Convert any URL to Markdown for better grounding LLMs.

## Summary

The Reader API is a tool designed to convert URLs into Markdown format, facilitating better integration and
understanding for language learning models (LLMs). By transforming web content into an easily readable and processable
format, the API enhances the grounding of LLMs, allowing them to better interpret and utilize the information found
online.

This feature is particularly useful for developers and researchers looking to incorporate accurate and structured data
from various web sources into their applications. The ability to convert diverse web pages into a standardized format
enables improved data accessibility and usability, streamlining the development process and advancing the capabilities
of artificial intelligence applications.
