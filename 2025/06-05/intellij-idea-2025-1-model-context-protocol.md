# IntelliJ IDEA 2025.1 - Model Context Protocol

[https://blog.jetbrains.com/idea/2025/05/intellij-idea-2025-1-model-context-protocol/](https://blog.jetbrains.com/idea/2025/05/intellij-idea-2025-1-model-context-protocol/)

## Description

As of its 2025.1 release, IntelliJ IDEA is now also fully MCP Client compatible. What does this mean for you?

## Summary

This article introduces the Model Context Protocol (MCP) as implemented in IntelliJ IDEA 2025.1, which enhances the IDE's capabilities by allowing it to interact with external data sources. Specifically, it provides a setup guide for enabling MCP Client functionality in IntelliJ IDEA, allowing users to leverage AI assistants for development tasks that include accessing databases and other data sources.

The MCP Client feature enables IntelliJ's AI Assistant to perform tasks that were previously not possible, such as inspecting database schemas directly within the IDE. The article provides detailed steps on how users can configure the MCP servers to enhance their coding experience, enabling commands that provide read-only database access and fostering improved interaction with tools within the development environment.

Overall, this update represents a significant advancement for IntelliJ IDEA users looking to integrate AI seamlessly into their development workflows, promising increased efficiency and productivity.
