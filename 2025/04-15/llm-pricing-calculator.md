# LLM pricing calculator

[https://tools.simonwillison.net/llm-prices](https://tools.simonwillison.net/llm-prices)

## Description

A tool to calculate the costs associated with input and output tokens for language models.

## Summary

The LLM pricing calculator provides a user-friendly interface for determining the costs of using language models by inputting the number of prompt and completion tokens. Users can specify their input and output token counts and respective costs per million tokens to calculate the total cost of a session. 

The cost calculation results are displayed in both dollars and cents, which allows for a clear understanding of expenses related to model usage. It's important to note that the prices listed may vary as they can be updated over time.
