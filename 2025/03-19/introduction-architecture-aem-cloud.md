# Introduction to the Architecture of Adobe Experience Manager as a Cloud Service

[https://experienceleague.adobe.com/en/docs/experience-manager-cloud-service/content/overview/architecture](https://experienceleague.adobe.com/en/docs/experience-manager-cloud-service/content/overview/architecture)

## Description

Introduction to the Architecture of Adobe Experience Manager as a Cloud Service.

## Summary

Adobe Experience Manager (AEM) as a Cloud Service provides a modular architecture designed for creating and managing impactful digital experiences. It features a logical architecture that encompasses various solutions including AEM Sites, AEM Assets, and AEM Forms, which can work collaboratively through composable services tailored to specific use cases. The architecture is built around a variety of environments including production, stage, development, and rapid development, facilitating an organized approach to application delivery and testing.

The service architecture supports multiple high-level composable services such as content management and experience delivery, utilizing a containerized system for dynamic scalability. Key components like the AEM Author and Publish tiers enable efficient content management and delivery, while new innovations streamline processes like content replication and performance metrics. This architecture's foundation allows for seamless updates and maintenance through an automated CI/CD service in Cloud Manager, ensuring optimal performance without downtime during updates.
