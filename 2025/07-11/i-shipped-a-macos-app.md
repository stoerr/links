# I Shipped a macOS App Built Entirely by Claude Code

[https://www.indragie.com/blog/i-shipped-a-macos-app-built-entirely-by-claude-code](https://www.indragie.com/blog/i-shipped-a-macos-app-built-entirely-by-claude-code)

## Description

How I built Context—a native macOS SwiftUI app for debugging MCP servers—almost entirely with Claude Code, and what I learned about building with AI coding agents.

## Summary

In this blog post, Indragie Karunaratne shares his journey of developing a macOS app named Context using AI coding assistant Claude Code. The app serves as a debugging tool for MCP servers, and Karunaratne highlights that nearly all of its 20,000 lines of code were generated by Claude, with him contributing less than 1,000 lines manually. The post outlines the tools, methodologies, and learning experiences gained while navigating the challenges of using Claude Code for software development.

Karunaratne discusses the advantages and limitations of Claude Code as an AI-enabled programming agent, describing its performance in writing Swift and SwiftUI code, handling UI complexities, and the importance of refining designs through iterative feedback. He emphasizes the necessity of comprehensive prompts and specifications to effectively harness the model's capabilities, along with exploring new paradigms for integrated development environments driven by AI.

The author reflects on how AI has transformed his ability to ship side projects efficiently, enabling him to rekindle his passion for coding and create software that integrates modern development techniques, all while raising questions about the future of coding tools and environments in the AI era.
