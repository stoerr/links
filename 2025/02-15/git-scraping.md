# Simon Willison - Git scraping

[https://simonwillison.net/series/git-scraping/](UNCHANGEABLEURLPLACEHOLDER)

## Description

A technique for scraping content into a Git repository to track changes to it over time.

## Summary

The webpage by Simon Willison discusses "Git scraping," which is an innovative scraping technique that allows users to periodically capture and store data from web sources into a Git repository. This method is particularly effective for tracking changes over time, enabling users to have a version-controlled history of the scraped data.

Willison shares various applications of this technique, illustrating its usefulness during emergencies such as the Irma hurricane, where data was collected to aid response efforts. He presents several case studies, detailing how Git scraping can be utilized to track vital information like public works data, utility outages, and tree inventories.

Moreover, the article encourages the use of Git for collaboration and historical tracking, emphasizing the potential for automation within this framework, such as using GitHub Actions to run scrapers regularly for up-to-date data. This resource serves as a guide for developers and data enthusiasts looking to enhance their scraping capabilities while maintaining a robust change history.
