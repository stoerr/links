# Resource Override - Chrome Web Store

[https://chromewebstore.google.com/detail/resource-override/pkoacgokdfckfpndoffpifphamojphii](https://chromewebstore.google.com/detail/resource-override/pkoacgokdfckfpndoffpifphamojphii)

## Description

An extension to help you gain full control of any website by redirecting traffic, replacing, editing, or inserting new content.

## Summary

Resource Override is a powerful Chrome extension designed for users who want to manipulate website content dynamically. It allows for the redirection of URLs, modification of request and response headers, and the injection of JavaScript and CSS on the fly—ideal for debugging and development purposes.

The tool has integrated presets to easily enable CORS and other common modifications, making it user-friendly even for those who may not have extensive programming knowledge. Users can create text documents and use the integrated file editor to work with unminified code directly.

With a solid rating and a commitment to privacy, this extension provides a straightforward way for developers to gain control over the web pages they are working on, enhancing their productivity and workflow.
