# Large Language Models can run tools in your terminal with LLM 0.26

[https://simonwillison.net/2025/May/27/llm-tools/](UNCHANGEABLEURLPLACEHOLDER)

## Description

LLM 0.26 introduces significant features that allow Large Language Models to utilize tools directly within terminal environments.

## Summary

LLM 0.26 has been released with a game-changing ability for Large Language Models (LLMs) to execute tools through command-line interfaces. This version enables models from OpenAI, Anthropic, and others to call any Python function as a tool, enhancing their capabilities significantly. Users can install and utilize tool plugins to extend the functionality of their models easily.

The update includes the ability to run tools synchronously and asynchronously, with support for tool debugging and interactions using various models, including gpt-4.1 and Qwen3. Moreover, developers can create their own ad-hoc command-line tools or utilize existing plugins to perform tasks like mathematical calculations or database queries in a more structured way. This development is envisioned to enable the construction of sophisticated applications and workflows utilizing LLMs as powerful agents that can interact with external functionalities seamlessly.
