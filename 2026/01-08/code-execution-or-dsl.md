# Code-Execution oder Domain-Specific Language (DSL)

[https://www.adesso.de/de/news/blog/code-execution-oder-domain-specific-language-dsl.jsp](https://www.adesso.de/de/news/blog/code-execution-oder-domain-specific-language-dsl.jsp)

## Description

Der Blog-Beitrag zeigt, wie Agentic AI effizient wird, ohne Sicherheit und Compliance zu opfern – mit Workflow-DSL statt ungeprüftem Code Mode.

## Summary

In diesem Blog-Beitrag wird die Diskussion über die Vor- und Nachteile von Code-Execution und Domain-Specific Languages (DSL) eingehend behandelt. Es wird erörtert, wie Agentic AI durch den Einsatz von Workflow-DSL eine Balance zwischen Effizienz und Sicherheit erreichen kann. 

Der Autor argumentiert, dass die Verwendung von DSL nicht nur die Effizienz steigert, sondern auch wichtige Sicherheits- und Compliance-Anforderungen berücksichtigt, die bei der Verwendung von nicht geprüften Code-Modusen oft vernachlässigt werden. Es wird angesprochen, welche Vorteile das Implementieren von Workflow-DSL für Unternehmen mit sich bringt und wie dies zur Risikominderung beiträgt.
